## 自己紹介文（bio）候補

**初期案（運用中〜2026/9/23まで）**
```
仕事も暮らしも"時短"がテーマ📱
効率化ガジェット・時短家電を実際に使ってレビュー
毎日の「あったら便利」を発信します
```

**改訂案（2026/9/23〜・競合10アカウント分析を反映、確定版）**
```
定時で帰りたい会社員へ
コンサル業界3年目、毎日9時-19時半勤務でへとへと💦
最近Claudeに課金してAI学習中🤖
時短ガジェット・効率化グッズを実際に試して発信📱
```

改訂理由（`competitor-analysis.md` の分析より）：伸びているアカウントのbioは「誰向けか→自分の立場と数字→発信内容→リンク」の4段構成が基本。
- 「定時で帰りたい会社員へ」で誰向けかを明確化
- 「コンサル業界3年目」「9時-19時半勤務」という具体的な数字・立場を追加（読者が「自分と同じ立場かも」と判断しやすくなる）
- 「最近Claudeに課金してAI学習中」で発展途上感を出しつつ、AI関連投稿（003番など）との一貫性も確保
- 絵文字（💦🤖📱）はbioに限り使用。本文側の「改行・絵文字は基本入れない」ルール（CLAUDE.md）とは別枠として扱う
- 注意点：業種＋経験年数＋勤務時間の組み合わせは身元がある程度絞られる情報になるため、会社名や具体的な業務内容までは書かない線引きにしている

**短縮版（文字数制限に収まらない場合）**
```
時短ガジェット/家電レビュー📱
効率化好き会社員の実体験ベース発信
```

※ Instagram側の文字数制限は実際に貼り付けて確認すること。テイスト違い（もっとカジュアル／もっと真面目）が欲しい場合は追加で相談する。

## トラブルシューティングメモ：Threadsアカウント作成エラー時の確認事項
1. Instagramアプリで一度ログインし直し、タイムラインが正常に見られるか確認
2. Threadsアプリを最新版にアップデート
3. Wi-Fi⇔モバイル回線を切り替えて再試行
4. 少し時間を置いて再試行（作成直後のInstagramアカウントは反映に数分〜数時間かかることがある）
5. それでもダメならThreadsアプリをアンインストール→再インストール、端末再起動
6. Instagram側でアイコン・ユーザーネームを設定してから再試行（プロフィール未設定だと弾かれるケースあり）
